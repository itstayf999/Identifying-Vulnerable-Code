# Identifying Vulnerable Code

## Academic Project
An academic project developed at the University of Tabuk for detecting vulnerable source code using Machine Learning, Deep Learning, and AI.

## Project Overview
A system that analyzes source code and classifies it as Secure or Vulnerable through trained models and AI-assisted analysis.

## Objectives
- Detect vulnerable source code.
- Compare ML and DL models.
- Develop a practical code security analysis application.

## Machine Learning and Deep Learning Models
- Logistic Regression
- Linear SVM
- LSTM

## Model Selection
Three models were developed and evaluated. Logistic Regression and Linear SVM achieved stronger results than LSTM on the available dataset.

## Application Features
- Source code analysis
- Vulnerability detection
- Security scoring
- ML, AI, and Hybrid analysis
- Multi-language support

## System Architecture
The system includes data preprocessing, model training, vulnerability classification, and a Flask-based web application.
